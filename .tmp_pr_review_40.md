### 4. History Format Mismatch

**Files:** `src/popup/Popup.tsx:66`, `server/planner.py:142-145`

Popup sends:
```typescript
const history = Array.from(filledIds).map(id => ({ targetId: id, result: 'OK' }));
```

Planner expects (line 144):
```python
f"- Action: {step.get('action')}, TargetId: {step.get('targetId')}, Result: {step.get('result', 'OK')}"
```

Missing `action` field in history objects. The planner will log `Action: None` for all entries.

**Fix:** Already applied — added `action: 'TYPE'` to history objects.

---

### 5. Unused Dead Code — Tab Query Not Used

**File:** `src/popup/Popup.tsx:34-35`

```typescript
const [tab] = await browser.tabs.query({ active: true, currentWindow: true });
if (!tab?.id) throw new Error('No active tab');
```

The `tab` variable is queried but never used — messages now go through `runtime.sendMessage` which handles tab resolution in the background. This check is now dead code and throws an error that can never trigger the intended path.

**Fix:** Already applied — removed dead code.

### 6. TypeScript Type Casts for sendMessage Results

**Files:** `src/entrypoints/background.ts:84`, `src/popup/Popup.tsx:103`
